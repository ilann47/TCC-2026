# Texto do TCC e protótipo Python

Esta pasta contém uma cópia da versão editável preparada para a Entrega 03 em 29/09/2026. O arquivo principal do texto é `modelo.tex`. Os capítulos estão em `Capitulos/`, as referências em `Configuracoes/` e os diagramas editáveis em `Diagramas/plantuml/` (`.puml`), acompanhados das imagens usadas no texto.

O protótipo Python original e seus testes estão em [implementacao](implementacao/README.md). Ele é independente da [implementação Java](../implementacao-java/README.md); não é necessário iniciar as duas linguagens simultaneamente para executar uma variante arquitetural. Cada implementação oferece seus próprios caminhos síncrono e assíncrono.

Os arquivos `.cls`, `.bst` e `cvs-id.def` são componentes do modelo acadêmico LaTeX, preservados com seus avisos de autoria e licença. A cópia não inclui imagens de exemplo do modelo que não são usadas no TCC, PDFs dos artigos citados, caches Python ou saídas intermediárias da compilação. O PDF entregue está em [entregas/entrega-03](../entregas/entrega-03/).
