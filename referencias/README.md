# Referências bibliográficas do TCC

Esta pasta contém, **na cópia local**, os 12 PDFs dos artigos que aparecem na bibliografia efetiva do TCC (`projeto-latex-java/Configuracoes/entrega01.bib` e `modelo.bbl`). Cada arquivo foi conferido como PDF válido e cópia idêntica ao acervo local de artigos utilizado no trabalho. Livros, tese, normas e materiais não citados não foram incluídos.

O repositório GitHub é público. **Três PDFs** têm licença identificada que permite redistribuir as cópias intactas nas condições indicadas em [Direitos e atribuição](DIREITOS_AUTORAIS.md); esses três estão versionados e vinculados abaixo. Os **outros nove** continuam apenas na cópia local, pois não foi confirmada permissão para republicá-los. O acesso público a um artigo não equivale, por si só, a autorização para hospedar seu PDF em outro site. A licença de qualquer outra parte deste repositório não se aplica automaticamente a esses trabalhos de terceiros.
