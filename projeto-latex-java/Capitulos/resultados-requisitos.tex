O núcleo e a camada experimental foram construídos, mas isso não autoriza somar todos os requisitos como integralmente comprovados. Permanecem o formulário dedicado, a cobertura temporal incompleta e propriedades não ensaiadas fora do ambiente local. A implementação dos instrumentos foi atendida mesmo quando seu resultado foi desfavorável à hipótese.
